# Frontend Industrial Components Map

This folder contains the reusable business widgets used across the application pages.

## Examples

- `MachineCard.tsx` - machine summary card
- `DiagnosticsPanel.tsx` - diagnosis summary blocks
- `IndustrialMap.tsx` - geography and machine markers
- `MachineModal.tsx` - machine detail modal
- `ChatWidget.tsx` - floating assistant widget

## Good mental model

Pages decide the layout and the user journey.
This folder provides the reusable building blocks shown inside those pages.
