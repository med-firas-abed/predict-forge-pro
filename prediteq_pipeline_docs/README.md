# Pipeline Notes Archive

This folder groups presentation support notes around the ML pipeline and the
project walkthrough. It is useful for speaking, orientation, and quick code
navigation, but it is not part of the active runtime code.

Use this folder for:

- oral support notes
- slide helper content
- quick path maps for code walkthroughs
- explanatory summaries of the ML pipeline

When you need the current truth, prefer:

- `README.md`
- `docs/JURY_CODE_TOUR.md`
- `INDEX_RESULTATS.md`
- `prediteq_ml/`
- `prediteq_api/`
- `prediteq_frontend/`

File guide:

- `ordered_project_paths.md` is a code-tour map
- `simulation_ml_pipeline_and_validation*.md` are explanation notes
- `oral_1min_rul_hi.md` and `slide_rul_hi.md` are presentation aids
