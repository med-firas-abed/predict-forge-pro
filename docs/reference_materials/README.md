# Reference Materials

These files are kept for jury/context/reference purposes only. They do not affect
the running product or deployment paths.

- `legacy_archives/` stores larger historical report bundles and templates kept as local references.
- `legacy_reports/` stores prior report artifacts kept as examples or historical context.
- `session_exports/` stores exported workspace/session notes kept for traceability.
- `visual_review/` stores screenshots and review images used for presentation/design feedback.
